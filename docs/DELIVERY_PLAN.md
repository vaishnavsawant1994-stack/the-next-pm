# Delivery plan — 2026 to 2029

| Phase | Target | Release gate |
|---|---|---|
| 0 — Charter, source rights, legal, UX | November 2026 | Named owner and reviewer, signed requirements and legal risk register |
| 1 — Web foundation and editorial data | November–December 2026 | Homepage, state browser, provenance schema, back-office plan, CI green |
| 2 — Early-2027 beta | December 2026–January 2027 | Five early states, 690 basic validated constituency records and official-source links |
| 3 — State election operations | 2027 official poll windows | Results/status updates with authorization, approvals, load test and correction flow |
| 4 — Gujarat and Himachal Pradesh | Later 2027 | 250 more basic seat records, reused quality standard |
| 5 — Nine 2028 state elections | 2028 | Archive, policy comparisons, multilingual and optional account features |
| 6 — Lok Sabha readiness | Early 2029 | Parliamentary-seat catalog, national dashboards and election-day rehearsals |
| 7 — 2029 Lok Sabha | Per official ECI schedule | Verified counting and public sources, incident operations |
| 8 — Permanent platform | Post-2029 | Maintained records and neutral governance explainers |

## Day-one priorities
1. Source registry and correction rules.
2. State / election / constituency identifiers; term versus polling-date distinction.
3. Reviewer-controlled import and publishing.
4. Election/state/seat public pages plus voter-services navigation.
5. Official results operations with safe failover.
6. Mobile accessibility, security and launch rehearsals.

## Critical scope boundary
The present commit is **a source-labeled frontend foundation only**, not a claim that all 124 roadmap page templates, 940 constituency records, official data connectors or security workflows are implemented. New features require data verification, testing and publication approval.
